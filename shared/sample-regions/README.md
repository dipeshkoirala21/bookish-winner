# Sample region packs

`kathmandu_core/` is a compact, real-data region committed to the repo so the game's **Explore** works on a fresh checkout, with no need to run the Python pipeline. It covers Swayambhunath → Thamel → Kathmandu Durbar Square → Pashupatinath → Boudhanath (bbox 85.283–85.375 E, 27.690–27.735 N), plus a coarse horizon out to the Langtang/Jugal Himalaya (levels 5–6 only). With the Wave 2 data (the RATR, JNCT, BFNT, PROP and RSTR chunks and the side files below) it is about 14.4 MB. Since the W2 detail pass every road carries its final game corridor (at least 4.8 m; `META` `"ratr_corridor": "final"`), buildings standing in a corridor are trimmed back to it (passages under houses keep the house), roads stop at temple and hero footprints, and bridges, flyovers, foot overbridges and underpasses carry absolute deck heights with 5.5 m under every deck and no steps (docs/DATA_FORMATS.md 1.10, 1.11 and 1.15); the car and bus routing profiles avoid gallis and other streets a car cannot use.

* `Ghumante → Project Setup` (and `Ghumante → Import Region Pack`) copy it into `game/Assets/StreamingAssets/Regions/`, which is git-ignored.
* Files: `kathmandu_core.ghpk` (tiles), `.search.ghsi`, `.route.ghrg`, `.transit.ghrt` (bus/micro/tempo routes and turn restrictions), `.curated.ghcd` (hero heritage records), `.aviation.json` (TIA runway, procedures and schedule; not for navigation), `hero_recipes.json` (the curated records as JSON, a temporary bridge), `kathmandu_core.manifest.json` and `BUILD_REPORT.md`. Formats: docs/DATA_FORMATS.md.
* Rebuild it with `cd pipeline && python build.py --region kathmandu_core`, then copy every file the manifest lists, plus the manifest and `BUILD_REPORT.md`, here. Refresh it rarely: every rebuild adds about 14 MB to git history.
* For the full valley, run `python build.py --region kathmandu_valley`, then **Ghumante → Import Region Pack**.
